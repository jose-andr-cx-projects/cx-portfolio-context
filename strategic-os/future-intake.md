# Future Strategic OS connection (not yet built)

**Intent:** From this *new Bitbucket-native portfolio architecture forward*, establish a deliberate connection to the personal Strategic OS in a later phase. This is **not** the old GitHub mirror bridge in another form.

## Future design conditions
- CoM systems remain the exclusive authoritative home of organisational project records.
- No automatic copying of project repos, meeting transcripts, personal/customer information, restricted internal content or privileged links into personal GitHub.
- Strategic OS may receive approved, appropriately abstracted programme-level strategic signals, transferable methods, design principles and career reflection where permitted.
- Approval must be based on information classification, authorised ownership, privacy/IP rules and destination controls.
- Intake must have provenance, review status, approval and ability to revoke or correct.
- Strategic OS continues its existing incubation/review/promotion lifecycle; no automatic acceptance of suggested insights.
- The future adapter/service is designed **in `jose-andr` later** only after CoM rules and operating requirements are agreed. Do not install integrations now.

## Candidate future interface (logical, not implemented)
`CoM Rovo review -> explicit release approval -> sanitized insight package -> Strategic OS intake review`.

## This staging package
Historical GitHub mirrors are not consumed or maintained for this integration. Any existing older plans are superseded by this fresh architecture.
